# Marmolería Benjamin — Sistema Administrativo (MVP)

Aplicación web administrativa completa para la gestión integral de marmolería:
- 📊 **Dashboard general:** Métricas de presupuestos, obras, facturación y alertas de vencimiento.
- 👥 **Gestión de Clientes:** CRUD completo, historial de compras, obras y cuenta corriente.
- 📄 **Presupuestos:** Cálculo automático por m², lista de adicionales, exportación a **PDF** y **Word (.doc)**, envío por WhatsApp.
- 🏗️ **Obras:** Seguimiento de estado, progreso de cobros y generación de Ficha Técnica / Orden de Trabajo (PDF/Word).
- 📦 **Stock e Inventario:** Control de placas, cortes y movimientos de entrada/salida.
- 🚚 **Proveedores:** Cuentas corrientes, facturas, notas de crédito/débito y pagos.
- 💰 **Cobros y Pagos:** Emisión de recibos oficiales de cobro exportables a PDF y Word.
- 📱 **Mobile-First:** Optimizado con barra de navegación inferior táctil, botón flotante (FAB), tarjetas móviles y formularios bottom-sheet.

## 🚀 Despliegue en Vercel

El proyecto incluye el archivo `vercel.json` configurado para servir automáticamente la carpeta `frontend/`.

1. Importar el repositorio en [Vercel](https://vercel.com).
2. Dejar la configuración predeterminada (no requiere comandos de build).
3. Hacer clic en **Deploy**.
